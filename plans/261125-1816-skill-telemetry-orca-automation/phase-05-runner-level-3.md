# Phase 5: Orca mức 3, máy runner 24/7

## Requirements

- Máy riêng (ví dụ Mac mini) cắm thiết bị test, chạy `orca serve` headless, ghép với Orca trên laptop bằng `orca environment add`.
- Automation của phase 3–4 chuyển sang `--host runtime:<environment-id>`.
- Giữ máy thức, tự khởi động lại runtime khi máy restart.
- Laptop chỉ dùng để duyệt decision gate.
